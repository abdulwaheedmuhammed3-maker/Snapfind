# Snapfind product outline

## MVP
1. Authentication
2. User-created public listing (display name, Snapchat handle, country, optional interests)
3. Discovery feed with country filter and search
4. Listing visibility toggle and deletion
5. Report/block flow
6. Admin moderation workflow

## Safety and privacy
- Opt-in listing publication
- No scraping, automated enumeration, or bulk harvesting
- Rate limits and abuse detection
- User reporting and removal
- Minimize stored data; never request Snapchat credentials
